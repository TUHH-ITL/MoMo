# MoMo

This is the repository of **MoMo**: An Open-Source **Mo**dular **Mo**bile Robot.

Find more information about MoMo in the [official documentation](https://tuhh-itl.github.io/MoMo/).

## Robot Localization Failure Prediction Dataset

Using MoMo with Isaac Sim we created the dataset for this [paper](https://proc.logistics-journal.de/article/view/1186). You can find the dataset and the USDs for the maps [here](https://tore.tuhh.de/entities/product/71944c77-d6f3-4ecf-9dce-805e51b3a57f). The ROS2 map files that correspond to the USDs can be found in `momo_navigation/maps`.
